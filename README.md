# time-keeper-windows

가족이 한 대의 윈도우 PC를 함께 쓸 때, 각자의 화면 사용 시간을 **감시가 아니라 인식**의 방식으로 다루는 작은 도구.

## 왜 만들었나

시중의 자녀 통제 소프트웨어는 대부분 '적대적 전제'로 설계되어 있다. 프로세스를 숨기고, 작업관리자 종료를 방어하고, 관리자 권한을 요구한다. 그래서 코드가 복잡해지고, 백신에 오탐되고, 무엇보다 **들켰을 때 신뢰를 잃는다.**

time-keeper-windows는 반대 방향을 택한다.

- 우회는 가능하다. 그 사실을 인정한다.
- 대신 남은 시간을 **항상 보여준다.** 숨지 않는다.
- 스스로 조절하는 연습을 돕는 것이 목표다.
- 기록은 벌주기 위한 증거가 아니라, 주말에 같이 보며 대화하는 자료다.

그래서 이 프로젝트에는 다음 기능이 **의도적으로 없다.**

| 넣지 않는 것 | 이유 |
|---|---|
| 프로세스 숨기기 / 트레이 아이콘 제거 | 숨는 도구는 신뢰를 못 만든다 |
| 작업관리자 종료 방어, 워치독 재실행 | 우회 방어는 목표가 아니다 |
| 관리자 권한 요구 | 필요 없다 |
| 앱별·사이트별 차단 | 시간 관리와 콘텐츠 검열은 다른 문제다 |
| 키로깅, 화면 캡처, 원격 감시 | 논외 |

## 무엇을 하나

- PC를 켜면 **"누가 컴퓨터를 쓸까요?"** 화면이 뜬다. 이름을 고르고, 개인 PIN을 정해 두었다면 입력하고 시작한다. 아무도 고르지 않으면 시간은 기록되지 않는다 — 잠금 화면이 아니다.
- 가족마다 프로필을 둔다: 평일/주말 한도, 한도 없이 기록만 하는 모드(어른용), '5분만 더' 규칙을 사람별로 정한다.
- 오늘 사용한 시간을 1분 단위로 누적한다. 재부팅해도 유지되고, 자정에 리셋된다.
- 화면 오른쪽 위에 남은 시간이 **항상** 떠 있다(옮긴 자리는 기억한다). 10분 / 5분 / 1분 남았을 때 미리 알린다.
- 한도에 도달하면 시간 카운트가 멈춘다. 안내 앞에서 잠깐 기다렸다 `5분만 더`를 눌러도 온전히 그만큼 쓸 수 있다.
- 시간이 다 되면 전체화면 안내가 뜬다. `5분만 더`(사람별 하루 횟수 제한, 연속 사용 허용 여부도 사람별), `관리자 PIN으로 연장`(+15/30/60분). 누른 사실은 기록에 남는다.
- `오늘은 여기까지`를 누르면 화면이 열려 정리할 시간을 주고, `지금 컴퓨터 끄기`로 직접 끄거나 5분 뒤 저절로 절전된다. 강제로 끄지 않는다 — 스스로 마무리하도록 돕는 것이다.
- 일시정지를 직접 누를 수 있다 (식사, 숙제 등). 30분 뒤 자동 재개되고, 이것도 기록에 남는다.
- **기록 보기** 화면에서 가족별 오늘·이번 주·최근 4주 사용량을 본다. 원본은 CSV라 엑셀로도 열린다.

자세한 동작 규칙은 [SPEC.md](SPEC.md) 참고.

## 설치

가족 PC(윈도우 10/11)에서 한 번만 하면 된다. 두 가지 방법 중 하나를 고른다.

### 방법 A — exe 다운로드 (파이썬 설치 불필요, 쉬움)

1. **다운로드** — 이 저장소의 [Releases](../../releases)에서 `time-keeper-windows.exe`를 받는다.
   지우지 않을 위치(예: `C:\Users\이름\time-keeper-windows\`)에 둔다.
2. **실행** — exe 더블클릭. 처음엔 **"Windows의 PC 보호"** 경고가 뜰 수 있다 →
   `추가 정보` → `실행`. (서명하지 않은 개인 제작 앱이라 뜨는 안내다. 하는 일은 이 저장소에 전부 공개돼 있다.)
   화면 오른쪽 위에 위젯이 뜨면 성공.
3. **첫 설정** — 위젯 우클릭 → `설정 (관리자)` → 관리자 PIN 만들기 → 가족 이름·한도 입력.
   개인 PIN은 각 줄의 `만들기` 버튼으로.
4. **자동 실행** — 설정 화면의 `자동 실행: 등록하기` 버튼 한 번.

### 방법 B — 파이썬으로 직접 실행 (오탐 걱정 없음)

1. **파이썬 설치** — [python.org/downloads](https://www.python.org/downloads/)에서 최신 버전.
   설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**한다.
2. **패키지 설치** — 명령 프롬프트(cmd)에서 `pip install customtkinter`
3. **다운로드** — 이 저장소를 받는다 (초록색 `Code` 버튼 → `Download ZIP` → 압축 해제).
4. **실행** — `time_keeper.pyw` 더블클릭. 이후 설정·자동 실행은 방법 A의 3~4와 같다.
   (자동 실행을 수동으로 하려면: `Win+R` → `shell:startup` → 열린 폴더에 바로가기를 넣는다)

## 끄는 방법 (숨기지 않는다)

위젯에는 닫기 버튼이 없다. 항상 보이는 것이 이 앱의 핵심 기능이기 때문이다.
Alt+F4로도 닫히지 않는다 — 창만 닫히고 프로그램이 백그라운드에 남으면 위젯이 안 보이는데
새로 켜지지도 않는 상태가 되기 때문이다.

앱을 끝내려면 **위젯 우클릭 → `종료 (관리자)`** 를 쓴다. 관리자 PIN을 넣어야 꺼진다
(관리자는 깔끔히 끄고, 아이는 눌러서 타이머를 피하지 못하게). 꺼져 있는 동안의 시간은 기록되지 않는다.

혹시 위젯이 사라졌는데 `이미 실행되고 있어요`가 뜬다면, 이전 프로그램이 백그라운드에 남은 것이다.
작업 관리자(`Ctrl+Shift+Esc`)의 **`자세히`(Details) 탭**에서 `pythonw.exe`를 끝내면 된다.
(이 앱은 창 장식이 없어 작업표시줄·`프로세스` 탭에는 안 보이고 `자세히` 탭에만 보인다.)

## 데이터는 어디에

`%LOCALAPPDATA%\time-keeper-windows\` 아래 파일 세 개가 전부다.

| 파일 | 내용 |
|---|---|
| `config.json` | 가족 프로필과 설정 |
| `state.json` | 오늘 상태 (몇 분 썼는지 등) |
| `log.csv` | 일별 기록 — 엑셀로 바로 열린다 |

## 상태

MVP 구현됨 — Python + customtkinter, 단일 파일 [`time_keeper.pyw`](time_keeper.pyw).
